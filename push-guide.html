한끗독서 앱 열기

🔔 알림 켜는 방법

알림을 켜면 매일 한 장을 잊지 않고, 책 받는 날과 후기 기한 소식도 놓치지 않아요. 한 번만 하면 돼요.

⚠️ 아이폰은 홈 화면에 추가를 해야 알림이 와요. 그냥 사파리로만 쓰면 알림을 켤 수 없어요. 아래 순서대로 따라 해 주세요.
1사파리로 열기

book.youthvoice.or.kr 을 사파리(파란 나침반 아이콘)에서 열어요.

카카오톡이나 인스타그램 안에서 열면 안 돼요. 그럴 땐 오른쪽 아래 ⋯ 를 눌러 「사파리로 열기」를 골라 주세요.
2공유 버튼 누르기

화면 아래 가운데에 있는 네모에 위쪽 화살표(⬆︎) 모양 버튼을 눌러요.

⬆︎
화면 아래 가운데네모 위에 화살표가 있는 버튼
3「홈 화면에 추가」 고르기

나온 메뉴를 위로 올리면 「홈 화면에 추가」가 보여요. 누른 뒤 오른쪽 위 「추가」를 눌러요.

➕
홈 화면에 추가안 보이면 메뉴를 위로 쓸어 올려요
4홈 화면의 아이콘으로 다시 열기

휴대폰 홈 화면에 생긴 한끗독서 아이콘을 눌러 열어요. 꼭 이 아이콘으로 열어야 해요. 사파리로 다시 열면 알림을 켤 수 없어요.

📱
홈 화면의 한끗독서사파리가 아니라 이 아이콘
5「알림 켜기」 → 「허용」

로그인하면 홈 위쪽에 「알림 켜기」가 나와요. 눌러서 나오는 창에서 「허용」을 눌러요. (안 보이면 MY → 알림에서 켤 수 있어요.)

끝! 알림이 켜졌어요 🎉MY → 알림에 「켜져 있어요」가 보이면 성공이에요
1크롬으로 열기

book.youthvoice.or.kr 을 크롬에서 열어요. 카카오톡 안에서 열었다면 오른쪽 위 ⋮ → 「다른 브라우저로 열기」를 골라요.

2홈 화면에 추가

오른쪽 위 점 세 개(⋮)를 누르고 「홈 화면에 추가」(또는 「앱 설치」)를 눌러요. 나오는 창에서 「추가」(「설치」)를 눌러요.

⋮
오른쪽 위 점 세 개홈 화면에 추가 · 앱 설치
3「알림 켜기」 → 「허용」

홈 화면의 한끗독서 아이콘으로 열고 로그인해요. 홈 위쪽 「알림 켜기」를 누른 뒤 나오는 창에서 「허용」을 눌러요. (안 보이면 MY → 알림)

끝! 알림이 켜졌어요 🎉MY → 알림에 「켜져 있어요」가 보이면 성공이에요

알림이 안 와요

「알림 켜기」를 눌렀는데 아무 일도 없어요 (아이폰)
  • 사파리가 아니라 홈 화면의 한끗독서 아이콘으로 열었는지 확인해 주세요.
  • 아이폰은 iOS 16.4 이상이어야 해요. 설정 → 일반 → 소프트웨어 업데이트에서 확인해요.
「알림이 막혀 있어요」라고 나와요
  • 아이폰: 설정 → 알림 → 한끗독서 → 알림 허용을 켜 주세요.
  • 안드로이드: 설정 → 앱 → 한끗독서(또는 크롬) → 알림 → 허용으로 바꿔 주세요.
  • 바꾼 뒤 앱을 완전히 닫았다가 다시 열어 주세요.
켜져 있다는데 알림이 안 와요
  • 방해금지·집중 모드가 켜져 있으면 알림이 조용히 쌓여요. 잠시 꺼 두고 확인해 주세요.
  • MY → 알림에서 한 번 끄고 다시 켜면 새로 연결돼요.
  • 휴대폰을 바꿨거나 앱을 지웠다면 위 순서를 처음부터 다시 해 주세요.
알림을 끄고 싶어요

앱의 MY → 알림에서 「끄기」를 누르면 돼요. 받고 싶은 소식(친구들 소식, 콕)과 매일 리마인더 시각도 거기서 고를 수 있어요.

그래도 안 되면 카카오톡 채널로 문의해 주세요.
